# House Price Prediction Using Linear Regression

## Project Overview

This project predicts house prices using Multiple Linear Regression.

The model is trained on housing data and uses features such as:

- Area
- Bedrooms
- Bathrooms
- Stories
- Main Road Access
- Guest Room
- Basement
- Air Conditioning
- Parking
- Preferred Area
- Furnishing Status

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn
- Jupyter Notebook

---

## Machine Learning Workflow

1. Data Loading
2. Data Preprocessing
3. Feature Encoding
4. Train-Test Split
5. Linear Regression Model Training
6. Model Evaluation

---

## Evaluation Metrics

- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- Mean Absolute Error (MAE)
- R² Score

### Results

| Metric | Value |
|----------|----------|
| Train R² | 0.686 |
| Test R² | 0.653 |

The model explains approximately 65% of the variation in house prices and generalizes reasonably well on unseen data.

## Dataset

Housing dataset containing various house attributes and their corresponding prices.
